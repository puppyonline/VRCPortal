VRChat Portal

A comprehensive, self-hosted application for exploring the VRChat API. Available as a cross-platform desktop app or a local web tool.

Download Desktop App View Source
Local Use Only - Use at Your Own Risk

This application runs on your own machine, for your own VRChat account. Do not deploy publicly or use to authenticate others. VRChat does not officially support their API - endpoints may break without notice.

What It Does

VRChat Portal gives you a clean, modern interface to browse nearly every piece of data available through VRChat's API - users, worlds, groups, avatars, instances, friends, favorites, economy, inventory, notifications, moderation, and more. Run it as a desktop app or in your browser.

Dashboard

Live player count, API status, server time, build version, and announcements.

Profile

Full profile view with presence, platform history, past names, status history, Steam integration.

Worlds & Groups

Search, browse, and view detailed info including active instances, members, roles, and posts.

Friends & Social

Online/offline lists, mutual counts, friend status, notifications, invites, and moderation.

Economy

Balance, earnings, subscriptions, token bundles, purchases, store, and Tilia status.

Inventory

Browse stickers, emojis, props, skins, effects, bundles, collections, and drops.

Avatars & Instances

Search avatars, look up instances by ID or short name, view recent locations.

Service Status

Real-time status from status.vrchat.com with component groups and incident timelines.

Quick Start

Desktop App (Recommended)

Download the latest release for your platform from the Releases page. The Windows installer includes auto-updates.

Web Mode

git clone https://github.com/puppyonline/VRCPortal.git
cd VRCPortal
npm install
npm run dev

Opens at http://localhost:5173. On first launch you'll be prompted to enter a contact email (required by VRChat's guidelines). Then log in and explore.

VRChat API Compliance

This project takes VRChat's Creator Guidelines seriously. Here's how each rule is addressed:

✅

Proper Identification

Every request includes VRChatPortal/1.0.0 your@email.com as the User-Agent. The app won't function until an email is configured.

✅

Rate Limiting & Caching

Exponential backoff on 429s (up to 60s). In-memory TTL cache for stable data. No automated polling or fixed-interval requests.

✅

No Content Upload

All world/avatar/prop/file creation endpoints are disabled. The app is read-only for content assets.

✅

No Credential Storage

Passwords are used for a single auth request and immediately discarded. Session is VRChat's own cookie. Nothing is persisted.

✅

Personal Use Only

Designed for self-hosted, single-user operation. You authenticate your own account from your own device and IP.

⚠️

Authentication Limitation

VRChat says "do not request credentials" but doesn't offer OAuth. This tool is for personal use only - you're authenticating yourself. Prominent warnings are displayed.

Limitations & Risks

  • Unofficial API - VRChat does not document or support their API. Endpoints may change or break without notice.
  • Account risk - Abuse of the API may result in account termination. Use responsibly.
  • No official support - Do not contact VRChat support about API issues.
  • Community-maintained - This project relies on vrchat.community documentation which is best-effort.
  • Local only - Do not deploy publicly. Do not authenticate other people's accounts.
